# مجلد ملفات cookies

ضع هنا ملف cookies المُصدَّر من المتصفح (بصيغة `.txt` أو `.json`) لحساب رسمي مسجّل الدخول.

- يُستخدم **أحدث ملف** في هذا المجلد تلقائياً، دون تعديل `.env` ودون إعادة البناء.
- المجلد مربوط بالحاوية (`/app/cookies`) ولا يُنسخ داخل صورة Docker ولا يُرفع على Git.
- للتحقق: `docker compose exec web python manage.py check_cookies`

⚠️ هذا الملف يمنح دخولاً كاملاً للحساب — لا تشاركه مع أحد.
