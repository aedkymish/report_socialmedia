# مجلد البيانات

يُربط هذا المجلد بالحاوية (`/app/data`) ويحتوي:

```
data/
├── db.sqlite3                     ← قاعدة البيانات
└── media/
    ├── evidence/request_<رقم>/link_<رقم>/   ← الفيديوهات والصور
    └── debug/                              ← لقطات أمر debug_profile
```

- **النسخ الاحتياطي**: أوقف الحاوية (`docker compose stop`) ثم انسخ المجلد كاملاً.
- لا تعدّل `db.sqlite3` أثناء تشغيل الحاوية.
- المجلد لا يُرفع على Git ولا يُنسخ داخل صورة Docker لأنه يحتوي أدلة وبيانات حساسة.
