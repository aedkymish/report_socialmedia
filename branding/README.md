# شعار المؤسسة

ضع ملف الشعار هنا (PNG أو JPG أو SVG أو WEBP، أقل من 2MB) ثم اضبط في `.env`:

```
REPORT_LOGO_PATH=branding/logo.png
REPORT_LOGO_HEIGHT=70
```

- يظهر الشعار في رأس تقرير PDF (يمين الصفحة) ويُضمَّن داخل الملف.
- المجلد مربوط بالحاوية (`/app/branding`)، فاستبدال الشعار لا يحتاج إعادة بناء.
- يُفضَّل PNG بخلفية شفافة.
